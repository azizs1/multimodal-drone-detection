# PostgreSQL Database for Incident Persistence

This directory contains the PostgreSQL database setup for persisting fused incident outcomes.

## Database Schema

The database is designed to store incident events generated by multimodal fusion.

### Tables

#### `incidents`
Stores drone incident events with fused model output and evidence snapshots.

| Column                  | Type             | Description                               |
| ----------------------- | ---------------- | ----------------------------------------- |
| `id`                    | UUID             | Primary key (auto-generated)              |
| `incident_id`           | VARCHAR(80)      | Stable incident id from fusion layer      |
| `detected_at`           | TIMESTAMPTZ      | Incident timestamp                        |
| `source_timestamp`      | DOUBLE PRECISION | Original Unix timestamp from payload      |
| `has_drone`             | BOOLEAN          | Whether payload indicates drone presence  |
| `decision`              | VARCHAR(10)      | Final decision (`drone` or `none`)        |
| `confidence_band`       | VARCHAR(10)      | Confidence band (`low`, `medium`, `high`) |
| `alert_level`           | VARCHAR(10)      | Derived alert level                       |
| `is_confirmed`          | BOOLEAN          | True when drone decision is confirmed     |
| `fused_confidence`      | DOUBLE PRECISION | Fusion confidence score (0.0-1.0)         |
| `stream_name`           | VARCHAR(100)     | Source stream label                       |
| `primary_frame_url`     | TEXT             | Canonical frame URI                       |
| `primary_thumbnail_url` | TEXT             | Canonical thumbnail URI                   |
| `per_modality_scores`   | JSONB            | Per-modality confidence map               |
| `thresholds`            | JSONB            | Threshold values used by fusion           |
| `gating_reason`         | TEXT             | Fusion gating explanation                 |
| `latency_ms`            | DOUBLE PRECISION | End-to-end fusion latency                 |
| `evidence`              | JSONB            | Structured evidence by modality           |
| `media`                 | JSONB            | Raw media references by modality          |
| `objects`               | JSONB            | Object-level confidences and metadata     |
| `created_at`            | TIMESTAMPTZ      | Record creation timestamp                 |
| `updated_at`            | TIMESTAMPTZ      | Record last update timestamp              |

**Indexes:**
- `idx_incidents_incident_id` - On `incident_id` for idempotent lookup
- `idx_incidents_detected_at` - On `detected_at DESC` for time-based queries
- `idx_incidents_decision` - On `decision` for filtering by decision class
- `idx_incidents_stream_name` - On `stream_name` for stream-level querying

## Usage

### Starting the Database

```bash
# Start all services including database
docker-compose -f docker-compose-dev.yml up -d

# Check database status
docker-compose -f docker-compose-dev.yml ps postgres

# View database logs
docker logs postgres
```

### Connecting to the Database

**From host machine:**
```bash
psql -h localhost -p 5432 -U droneuser -d drone_detection
# Password: dronepass
```

**From within Docker:**
```bash
docker exec -it postgres psql -U droneuser -d drone_detection
```

### Example Queries

**Insert an incident:**
```sql
INSERT INTO incidents (
    incident_id, detected_at, source_timestamp, has_drone, decision,
    confidence_band, alert_level, is_confirmed, fused_confidence, stream_name,
    primary_frame_url, per_modality_scores, thresholds, gating_reason,
    latency_ms, evidence, media, objects
)
VALUES (
    'incident-001', '2026-04-15T14:32:07Z', 1776263527.123, true, 'drone',
    'high', 'high', true, 0.94, 'fusion',
    's3://detections/drone/frame_001.jpg',
    '{"rgb":0.95,"thermal":0.90}'::jsonb,
    '{"alert":0.75,"hold":0.55}'::jsonb,
    'rgb+thermal',
    21.7,
    '{"rgb": {"modality":"rgb"}, "thermal": null}'::jsonb,
    '{"rgb": {"frame_uri":"s3://detections/drone/frame_001.jpg"}, "thermal": null}'::jsonb,
    '[]'::jsonb
);
```

**Get recent incidents:**
```sql
SELECT * FROM incidents
ORDER BY detected_at DESC
LIMIT 10;
```

**Get recent drone-positive incidents:**
```sql
SELECT * FROM incidents
WHERE decision = 'drone'
  AND detected_at > NOW() - INTERVAL '1 hour';
```

**Count incidents by hour:**
```sql
SELECT
    DATE_TRUNC('hour', detected_at) as hour,
    COUNT(*) as total_incidents,
    SUM(CASE WHEN decision = 'drone' THEN 1 ELSE 0 END) as drone_incidents,
    AVG(fused_confidence) as avg_confidence
FROM incidents
GROUP BY hour
ORDER BY hour DESC;
```

**Get incidents by stream and decision:**
```sql
SELECT
    stream_name,
    decision,
    COUNT(*) as count,
    AVG(fused_confidence) as avg_confidence
FROM incidents
GROUP BY stream_name, decision
ORDER BY count DESC;
```

**Find incidents with high modality disagreement:**
```sql
SELECT *
FROM incidents
WHERE ABS(
    COALESCE((per_modality_scores->>'rgb')::double precision, 0) -
    COALESCE((per_modality_scores->>'thermal')::double precision, 0)
) > 0.2
ORDER BY detected_at DESC;
```

## Backup and Restore

### Backup
```bash
# Backup entire database
docker exec postgres pg_dump -U droneuser drone_detection > backup.sql

# Backup with compression
docker exec postgres pg_dump -U droneuser drone_detection | gzip > backup.sql.gz
```

### Restore
```bash
# Restore from backup
cat backup.sql | docker exec -i postgres psql -U droneuser -d drone_detection

# Restore from compressed backup
gunzip -c backup.sql.gz | docker exec -i postgres psql -U droneuser -d drone_detection
```

## Database Management

### Reset Database
```bash
# Stop containers
docker-compose -f docker-compose-dev.yml down

# Remove database volume
docker volume rm multimodal-drone-detection_postgres-data

# Restart (will reinitialize database)
docker-compose -f docker-compose-dev.yml up -d
```
